# Documentation

Technical documentation for this project lives in this folder. The top-level [README](../README.md) is for users.

- [Repository setup](repo-setup.md): protections, ruleset and manual steps for new repos.
- [Development](development.md): layout, tooling, CI and releasing to PyPI.
- [Architecture](architecture.md): how checks, workflows, governance and releases fit together.
- [API reference](api.md): endpoints, settings, authentication modes and errors.
- [OpenAPI document](openapi.json): the machine-readable contract, generated from the code.
- [Deployment](deployment.md): domain, ports, HTTPS, reverse proxies and health probes.
- [Security](security.md): built-in protections and the automated security checks.
